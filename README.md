# 汽修记账助手 🚗🔧

个体汽修师傅专用的移动端记账 PWA 应用。

## 核心功能

- **语音录入**：点击 🎤 按钮，用普通话说话即可录入车牌、配件名
- **朗读播报**：点击任意记录或配件名，自动朗读文本内容（适配半文盲使用）
- **推荐定价**：输入配件成本+运费，系统自动计算推荐收费（可配置倍率）
- **图片识别**：拍销售单 → 通过 AI 识别自动填入（调用硅基流动 qwen-vl API，需自行扩展）
- **云端同步**：一键备份/恢复到中科院数据胶囊（WebDAV）
- **离线可用**：PWA 安装后，无网络也可正常记账

## 快速开始

### 方案一：直接使用（推荐）

1. 在手机上安装 **Chrome 浏览器**
2. 打开此应用（用你的服务器或 GitHub Pages 部署后）
3. 点击 Chrome 菜单 →「添加到主屏幕」
4. 以后从桌面图标打开，像原生 App 一样使用

### 方案二：本地开发调试

```bash
# 启动本地服务器
python3 -m http.server 8080
# 手机在同一局域网访问 http://你电脑IP:8080
```

### 部署到 GitHub Pages（免费）

```bash
cd /home/suli/garage-accountant
git init
git add .
git commit -m "init"
# 创建 GitHub 仓库，然后：
git remote add origin https://github.com/你的用户名/garage-accountant.git
git push -u origin main
# 在仓库 Settings → Pages → 选择 main 分支 → 部署
```

## 使用说明

### 记账流程

1. 点右下角 **+** 按钮
2. 选择日期、输入车牌号（可语音输入）
3. 点「添加配件/项目」，填写：
   - 配件名称（可语音）
   - 成本价（进价）
   - 运费（如果有）
   - 系统自动显示推荐价
   - 输入你决定的实收价格
4. 点「保存」
5. 回到首页查看所有记录

### 朗读功能

- 主页点击任意记录卡片 → 进入详情页
- 详情页点击任意配件行 → 朗读该行内容
- 点击 🔊 按钮 → 朗读配件名

### 定价规则配置

在设置页可调整：

| 参数 | 说明 | 默认值 |
|---|---|---|
| 加价倍率 | 成本 × 倍率 | 2.0 |
| 基础费 | 固定加价金额 | 0 |
| 取整到 | 向上取整到多少元 | 1 |

公式：**推荐价 = 向上取整(成本 × 加价倍率, 取整到) + 基础费**

### 数据同步（数据胶囊）

1. 进入设置页
2. 填写你的数据胶囊 WebDAV 信息（地址、用户名、密码）
3. 点「备份到数据胶囊」上传
4. 换手机或重装后，点「从数据胶囊恢复」

## 技术栈

- 纯 HTML + CSS + JavaScript（单文件，零依赖）
- PWA（Service Worker + manifest.json）
- Web Speech API（语音识别 + TTS 朗读）
- localStorage（本地数据持久化）
- WebDAV（中科院数据胶囊同步）
